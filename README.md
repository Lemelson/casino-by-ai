# 🎰 CASINO BY AI

Ретро-пиксельное казино в браузере — всё нарисовано кодом, без единого внешнего ассета.
Низкое внутреннее разрешение (320×180) с чётким целочисленным апскейлом, неоновая палитра,
синтезированный 8-битный звук. Чистый JavaScript + Canvas, без сборки.

## Игры

| Игра | Что внутри | RTP (отдача игроку) |
|------|------------|---------------------|
| 🎰 **Слоты** | 3 барабана, 5 линий (3 горизонтали + 2 диагонали), WILD, взвешенный RNG | ~95.95% |
| 🃏 **Блэкджек** | Шуз 4 колоды, hit/stand/double/split, дилер до 17, блэкджек 3:2 | ~94.4% (как дилер) / ~99.5% (базовая стратегия) |
| 🎡 **Рулетка** | Европейская (один зеро), колесо + шарик, интерактивный стол ставок | ~97.3% |
| 🪀 **Плинко** | 8 рядов пегов, честный биномиал, корзины с множителями до ×10 | ~96.56% |

Все игры откалиброваны на маленькую маржу казино — на короткой дистанции игрок реально
может выйти в плюс, но на длинной выигрывает заведение (как в настоящем казино).

## Запуск

Нужен любой статический сервер (сборка не требуется):

```bash
python3 -m http.server 8137
# открыть http://localhost:8137
```

## Управление

- **Лобби:** стрелки + Enter или клик по карточке игры.
- **Слоты:** `Space` — крутить, `−/+` — ставка.
- **Блэкджек:** `H` hit, `S` stand, `D` double, `P` split, фишки + `DEAL`.
- **Рулетка:** клик фишкой по столу, `Space`/`SPIN` — крутить.
- **Плинко:** `Space`/клик — бросить шарик (можно сыпать пачкой).
- Везде: `Esc` — в лобби, `M` — звук.

## Архитектура

```
src/
  engine/      палитра, рендерер-примитивы, пиксельный шрифт 5×7, ввод, синтез-звук,
               экономика (localStorage), менеджер сцен
  scenes/      lobby, slots, blackjack, roulette, plinko (+ арт карт/символов)
  main.js      игровой цикл, апскейл, регистрация сцен
```

Единая валюта-кошелёк на все игры. Новая игра = одна новая сцена + регистрация в `main.js`.
